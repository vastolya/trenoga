# Маша Тренога — архив 2018–2025

Прототип портфолио на Next.js App Router и Three.js. Работы, фотографии и PDF взяты из предоставленных материалов. Оригиналы не изменены.

## Запуск в Windows

```powershell
cd artist-site
npm.cmd install
npm.cmd run dev
```

Открыть http://127.0.0.1:3000.

```powershell
npm.cmd run build
```

Статический сайт будет в `out/`. Публикация ещё не выполнена. Идентификатор созданного приватного проекта сохранён в `.openai/hosting.json`.

## Что реализовано

- Единый фиксированный фон Three.js под всей страницей: медно-чёрные тени реагируют на указатель, нажатие и прокрутку; при наведении или фокусе на работе фон становится светлее. Секции прозрачные, самостоятельные переходные полосы удалены. Есть статический фон без WebGL, поддержка reduced motion и ограничение до 30 кадров/секунду; в скрытой вкладке отрисовка приостановлена.
- Архив по папке `../chronology`: 2025 / фреска; 2021–2024 / улица; 2021–2024 / линогравюра; 2018–2021 / ранние работы. Все 38 изображений подготовлены в WebP и представлены на сайте. Общие виды, детали и процесс одной работы объединены в проекты с дополнительными ракурсами. Серия «Ничего страшного» остаётся отдельной главой.
- Крупные работы на всю ширину и асимметричные пары графики. Изображение и подпись имеют общую ширину. Даты и размеры взяты из имён файлов; для недатированных изображений указан период группы. Экранные размеры не передают физические пропорции буквально.
- Модальное окно открывает отдельную работу: миниатюры, локальный счётчик и листание её снимков стрелками и с клавиатуры. Между разными работами просмотр не переключается. Для одного снимка лишние элементы управления скрыты; Escape закрывает окно.
- История выставки, скачивание исходного текста, фото художницы и ссылка на PDF.
- Адаптивная вёрстка и поддержка reduced motion.

Номера в названиях работ серии — номера исходных файлов, а не авторские названия. Часть текста адаптирована для сайта. «Уличная композиция», «Работа над росписью» и «Фреска для биеннале» — описательные подписи для файлов без авторских названий. Контакты Telegram и Instagram предоставлены пользователем.

Архивные данные: `app/chronology.ts`, перечень исходников — `chronology-sources.json`, компонент — `app/Archive.tsx`, сетка — `app/chronology.css`. Подготовка веб-изображений из папки материалов: `node scripts/prepare-chronology.mjs`.

Раздел «Ничего страшного» включает всю папку материалов: 17 работ / 19 изображений. Встроенные изображения из `1.ai` и `17.ai` извлечены без изменения оригиналов; это дополнительные экспорты «Сердцеедов» и «Хоровода», они доступны в модальных галереях этих работ. Данные — `app/exhibition-works.json`, подготовка — `node scripts/prepare-exhibition.mjs`.

## Проверка

После обновления хронологии `npm.cmd run build` выполнен успешно, включая проверку TypeScript и статический экспорт. Проверено присутствие всех 38 изображений и четырёх якорей разделов в собранной странице. Локальный сервер на http://127.0.0.1:3000 отвечает HTTP 200. Визуальная проверка в браузере не выполнена.

Стиль: прямой гротеск, медь и чёрно-белая палитра, SVG-зерно, потёртости и царапины. Искажения применены к отдельному фону; изображения работ и полноэкранный просмотр остаются чёткими. Фон замкнут: прогресс прокрутки задаёт полный оборот пространственной фазы, а плотность тени одинаковая в начале и конце документа. В середине архива тень рассеивается; возле футера снова собирается. Движение во времени и реакция на указатель продолжаются. Сетка архива — `app/archive.css`, единое окружение — `app/atmosphere.css` и `app/Scene.tsx`, фактура — `public/grain.svg` и `public/wear.svg`.

Временная копия npm-кэша находится в `C:\Users\param\AppData\Local\Temp\artist-npm-cache`. Копирование остановилось из-за нехватки диска; автоматическая проверка разрешений отклонила удаление этой временной папки. Её можно удалить вручную.
